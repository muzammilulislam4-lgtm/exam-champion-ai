EXAM CHAMPION AI — FREE PWA PACKAGE

What's included:
- index.html: the current interactive prototype
- manifest.json: app name, theme and install settings
- sw.js: basic offline caching
- icon.svg: app icon

IMPORTANT:
This is an installable web-app package, not a native Android APK.
To install it from Chrome, it must first be hosted on an HTTPS website.
The current prototype still uses sample questions; verified official syllabi,
previous-year papers, live current affairs, secure accounts, and a real admin
backend have NOT been connected yet.

FREE HOSTING OPTION (GitHub Pages):
1. On GitHub, create/sign in to a free account.
2. Create a new public repository, for example: exam-champion-ai.
3. Upload all four files from this folder to the repository's root.
4. Open the repository's Settings -> Pages.
5. Choose deployment from the main branch and root folder, then Save.
6. Wait for GitHub Pages to show the published HTTPS site address.
7. Open that address in Chrome on your Android tablet.
8. Tap Chrome's three-dot menu and choose "Install app" or "Add to Home screen".

If the app doesn't update after a change, close it and reopen it; service-worker
caching can keep the previous version briefly. A versioned cache name can be
changed in sw.js for later updates.

No paid hosting is required for this static prototype. A real app with accounts,
cloud-saved results, AI-generated questions, and regularly updated current
affairs would need a backend and data sources; free tiers may have limits.
